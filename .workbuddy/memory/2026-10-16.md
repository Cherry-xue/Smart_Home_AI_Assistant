这是**数据笔误**，不是设计意图——文档通篇只说"两室一厅"，而两室一厅本身就是单层户型。
我当时看到 floor 有 1 和 2 就推成了复式，没去质疑这个字段。

### ⚠️ 必须记住的坑
`04_seed.sql` 用的是 **`INSERT IGNORE`** —— 对已存在的行**不会更新**。
所以**只改种子文件修不了已有库**，必须在库里执行 UPDATE：
```sql
USE smart_home;
UPDATE rooms SET floor = 1 WHERE floor <> 1;
SELECT code, name, floor, sort_no FROM rooms ORDER BY sort_no;
```
（`floor` 字段本身保留，将来真有多层住宅可直接用。）

**✅ 11:17 用户开启虚拟机后已同步完成**：`UPDATE rooms SET floor=1 WHERE floor<>1`
实测受影响 2 行（主卧/次卧），复核 7 间房 `floor` 取值集合 = {1}。种子文件与库现已一致。
